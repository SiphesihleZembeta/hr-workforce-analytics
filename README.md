# HR Workforce Analytics Project

## Overview
This project is a collaborative Python-based workforce analytics solution developed as part of postgraduate data science coursework at the University of the Witwatersrand.

The objective of the project was to transform raw employee workforce data into structured, analysable information through data cleaning, validation, testing, and workforce analytics.

## Project Objectives
- Clean and preprocess workforce data
- Handle missing and inconsistent data
- Validate data quality and integrity
- Generate workforce insights from employee datasets
- Perform workforce metric analysis
